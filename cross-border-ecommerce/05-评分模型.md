# 跨境电商/品牌出海 · 评分模型

> **目标**: 1-100 分量化评估跨境电商客户的信贷价值
> **用途**: A/B/C 分层 + 决策矩阵 + 一票否决

---

## 一、5 大评分维度(总分 100)

### 维度 1:产品与品类(20 分)

| 子项 | 满分 | 评分标准 |
|---|---|---|
| 自有品牌占比 | 6 分 | ≥80% 6 分 / 50-80% 4 分 / <50% 1 分 |
| SKU 结构 | 5 分 | 分散(>20 SKU)5 分 / 中等(5-20)3 分 / 集中(<5)1 分 |
| 客单价 | 4 分 | ≥$100 4 分 / $30-100 2 分 / <$30 1 分 |
| 品类毛利率 | 5 分 | ≥50% 5 分 / 30-50% 3 分 / <30% 1 分 |

**打分要点**:
- 自有品牌 = 议价权 + 抗风险
- SKU 太集中 = 单品失败 = 公司失败
- 客单价高 = 利润空间大
- 毛利率 < 30% = 价格战激烈

### 维度 2:渠道与平台(20 分)

| 子项 | 满分 | 评分标准 |
|---|---|---|
| 平台分散度 | 8 分 | 3+ 平台 8 分 / 2 平台 5 分 / 单平台 0 分 |
| 独立站占比 | 6 分 | ≥30% 6 分 / 10-30% 3 分 / <10% 1 分 |
| 市场分散度 | 6 分 | 3+ 国家 6 分 / 2 国家 3 分 / 单国 1 分 |

**打分要点**:
- 单平台 100% = 一票否决
- 独立站占比 = 抗平台风险能力
- 多市场 = 抗单一市场风险

### 维度 3:运营与营销(20 分)

| 子项 | 满分 | 评分标准 |
|---|---|---|
| Amazon BSR Top 10 SKU | 8 分 | Top 100 8 分 / Top 1000 5 分 / 其他 2 分 |
| Review 评分 | 4 分 | ≥4.5 4 分 / 4.0-4.5 2 分 / <4.0 0 分 |
| 广告占比 | 4 分 | <15% 4 分 / 15-25% 2 分 / >25% 0 分 |
| 退货率 | 4 分 | <10% 4 分 / 10-20% 2 分 / >20% 0 分 |

**打分要点**:
- BSR 排名 = 真实市场地位
- Review < 4.0 = 销售下滑信号
- 广告占比 > 25% = 流量成本失控
- 退货率高 = 资金沉淀严重

### 维度 4:财务与合规(20 分)

| 子项 | 满分 | 评分标准 |
|---|---|---|
| 年营收规模 | 6 分 | ≥1 亿 6 分 / 3000 万-1 亿 4 分 / <3000 万 1 分 |
| 营收增长率 | 4 分 | ≥50% 4 分 / 20-50% 2 分 / <20% 1 分 |
| 净利率 | 4 分 | ≥15% 4 分 / 5-15% 2 分 / <5% 0 分 |
| 合规完备性 | 6 分 | CE/FCC/EPR/VAT 齐全 6 分 / 部分 3 分 / 缺失 0 分 |

**打分要点**:
- 跨境电商净利率 5-15% 是健康水平
- < 3% 长期不可持续
- 合规缺失 = 下架风险

### 维度 5:团队与治理(20 分)

| 子项 | 满分 | 评分标准 |
|---|---|---|
| 创始人行业经验 | 5 分 | 5+ 年跨境 5 分 / 2-5 年 3 分 / 首次 0 分 |
| 核心团队稳定性 | 4 分 | 3 年以上稳定 4 分 / 有流失 2 分 / 频繁变动 0 分 |
| 实控人持股 | 4 分 | >50% 4 分 / 30-50% 2 分 / <30% 1 分 |
| 团队规模与结构 | 4 分 | >50 人 + 结构合理 4 分 / 20-50 人 2 分 / <20 人 1 分 |
| 外部投资人背书 | 3 分 | 头部 VC 3 分 / 普通 VC 1 分 / 无 0 分 |

**打分要点**:
- 跨境电商老板多是销售出身,运营能力 > 管理能力
- 创始团队稳定性(选品/运营/供应链)
- 团队结构:运营 vs 供应链比例

## 二、一票否决红线(任一触发 = 0 分)

### 🔴 红线清单(不碰)

| 红线 | 说明 |
|---|---|
| 单平台 100%(Amazon 占比 > 90%) | 封号 = 公司死亡 |
| 历史封号记录 | 二次封号概率极高 |
| 净利率 < 3%(持续 2 年) | 不可持续 |
| 退货率 > 30% | 利润侵蚀严重 |
| 大股东质押 > 50% | 资金链紧张 |
| 涉及刷评 / 违规运营 | 平台黑名单 |
| 核心合规缺失(CE/FCC/VAT) | 下架风险 |
| 汇率敞口 > 80% + 未套保 | 汇率风险致命 |
| 实控人失信 / 涉诉 | 一票否决 |

## 三、A/B/C/D 分层决策

### A 类(90-100 分):重点跟进

- 7 天内提交授信方案初稿
- 优先级产品匹配:
  - 流水贷(基于 PingPong/连连收款)
  - 海外仓存货质押
  - 应收账款融资(Amazon 2P)
- 联合尽调 + 内部白名单
- 季度跟踪

### B+ 类(75-89 分):积极培育

- 14 天内提交授信方案
- 主流产品(流水贷 + 应收 + 存货质押)
- 半年跟踪 + 关键节点对接
- 培养 12 个月,争取升级 A 类

### B 类(60-74 分):观察培育

- 30 天内提交初步方案
- 单一产品(流水贷或存货质押)
- 年跟踪 + 重要节点对接
- 条件改善可升级

### C 类(45-59 分):暂缓

- 暂不主动授信
- 季度简单回访
- 等待条件改善

### D 类(<45 分):不建议介入

- 直接放弃,不留面子
- 不投入后续精力

## 四、评分实操流程

### 第 1 步:红线检查(5 分钟)

✅ 全部通过 → 进入评分
❌ 任一触发 → 直接 D 类

### 第 2 步:数据验证(必查)

#### 平台数据

- [ ] Amazon BSR Top 10 SKU
- [ ] Review 评分 + 数量
- [ ] Brand Registry 状态
- [ ] 店铺绩效(ODR, Late Shipment Rate)

#### 财务数据

- [ ] PingPong/连连/WF 月流水(近 6 个月)
- [ ] 银行流水(近 6 个月)
- [ ] 财务报表

#### 合规数据

- [ ] CE/FCC/FDA 认证
- [ ] VAT 税号
- [ ] EPR 注册

#### 库存数据

- [ ] FBA 库存报表
- [ ] 海外仓分布 + 利用率
- [ ] 库存周转天数

### 第 4 步:总分计算 + 分层(5 分钟)

### 第 5 步:输出评分报告(30 分钟)

## 五、案例演练

### 案例 1:深圳某 3C 数码品牌

| 维度 | 子项 | 评分 | 备注 |
|---|---|---|---|
| 产品 | 自有品牌 90% + 30 SKU + 客单价 $50 + 毛利 60% | 18/20 | 产品健康 |
| 渠道 | Amazon 50% + TikTok Shop 30% + 独立站 20% + 美欧东南亚 | 20/20 | 渠道分散 |
| 运营 | BSR Top 500 + Review 4.5 + 广告 12% + 退货 8% | 20/20 | 运营优秀 |
| 财务 | 营收 2 亿 + 增长 60% + 净利率 12% + 合规齐 | 17/20 | 合规齐 |
| 团队 | 创始 8 年 + 核心稳定 + 实控人 60% + 团队 80 人 + 红杉 | 18/20 | 团队强 |
| **总分** | | **93/100** | **A 类** |

**结论**: 全维度优秀,银行重点客户.
- 重点产品:流水贷 + 海外仓存货质押 + 应收账款融资
- 建议:全套产品组合授信,争取主结算行

### 案例 2:深圳某服装铺货卖家

| 维度 | 子项 | 评分 | 备注 |
|---|---|---|---|
| 产品 | 平台店群(无品牌) + 1000+ SKU + 客单价 $25 + 毛利 40% | 7/20 | 铺货模式 |
| 渠道 | Amazon 100% + 美国单市场 | 0/20 | 渠道风险 |
| 运营 | BSR 中等 + Review 4.0 + 广告 25% + 退货 25% | 5/20 | 运营一般 |
| 财务 | 营收 5000 万 + 增长 30% + 净利率 3% + 合规缺 | 4/20 | 财务弱 |
| 团队 | 创始 3 年 + 团队 20 人 + 实控人 70% + 无 VC | 9/20 | 团队弱 |
| **总分** | | **25/100** | **D 类** |

**结论**: 单一平台 + 铺货模式 + 净利率低 = 高风险. 不建议介入.

### 案例 3:深圳某智能家居品牌

| 维度 | 子项 | 评分 | 备注 |
|---|---|---|---|
| 产品 | 自有品牌 100% + 5 SKU + 客单价 $500 + 毛利 65% | 18/20 | 高客单价 |
| 渠道 | Amazon 60% + 独立站 30% + 线下 10% + 美国 + 欧洲 | 17/20 | 渠道分散 |
| 运营 | BSR Top 100 + Review 4.7 + 广告 15% + 退货 5% | 20/20 | 运营优秀 |
| 财务 | 营收 1.5 亿 + 增长 80% + 净利率 18% + 合规齐 | 19/20 | 财务强 |
| 团队 | 创始 6 年 + 团队 50 人 + 实控人 45% + 高瓴 | 15/20 | 团队强 |
| **总分** | | **89/100** | **B+ 类** |

**结论**: 高客单价 + 强品牌 + 多渠道. 银行积极培育.
- 重点产品:流水贷 + 海外仓存货质押 + 知识产权质押
- 建议:季度跟踪,1 年内争取升级 A 类

## 六、评分校准与复盘

### 每月回顾

- A 类客户是否真的优质?
- B+ 类升级为 A 的比例(目标 30%+)
- C 类改善并升级的比例(目标 10%+)
- D 类是否真的不该碰?

### 季度校准

- 评分标准是否需要调整?
- 红线是否需要增减?
- 维度权重是否需要调整?
- 新增平台规则(TikTok Shop / Temu)是否需要纳入?

### 复盘机制

- 客户违约 → 复盘评分哪里漏了
- 客户超预期 → 复盘评分哪里过严
- 季度汇总,迭代模型
