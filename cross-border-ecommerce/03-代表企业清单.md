## 七、不建议介入的清单

| 类型 | 原因 |
|---|---|
| 单平台依赖 100%(Amazon 占比 > 90%) | 封号风险 |
| 库存周转 > 120 天 | 滞销风险 |
| 退货率 > 30% | 利润侵蚀 |
| 利润对汇率高度敏感 + 未做套保 | 汇率风险 |
| 合规不达标(CE/FCC/EPR 缺失) | 下架风险 |
| 涉及刷评/违规运营历史 | 平台黑名单 |
| 大股东股权质押 > 50% | 资金链紧张 |
| 跨境通、有棵树 等业绩爆雷企业 | 经营风险 |
