# 跨境电商/品牌出海 · 首次拜访清单

> **场景**: 客户经理对跨境电商小微客户的首次拜访
> **目标**: 1 小时内完成"行业了解 + 初步筛选",判断是否值得深耕

---

## 拜访前准备(30 分钟)

### 资料收集(必做)

- [ ] 公司官网 / Amazon 店铺(品牌 + 产品 + 销量)
- [ ] Helium10 / Jungle Scout(销量估算、关键词排名、竞品分析)
- [ ] 工商信息(企查查/天眼查):成立时间、股东、诉讼
- [ ] 36氪 / IT桔子:融资信息、最新动态
- [ ] 招聘数据(拉勾/BOSS 直聘):团队扩张信号
- [ ] SimilarWeb:独立站流量分析

### 5 个开场问题(避免冷场)

1. "你们从哪个品类起家?怎么找到这个品类的?"
2. "现在 Amazon 上卖的最好的产品是哪个?月销多少?"
3. "你们主要走平台还是独立站?为什么?"
4. "现在最大的挑战是什么?(平台/物流/资金/团队)"
5. "我看你们在招 XX 岗位,是在扩张吗?"

## 拜访中:30 个核心问题

### 🏭 一、公司基本面(5 题)

1. 公司成立时间?最初做哪个品类?
2. 现在的股权结构?实控人持股比例?
3. 核心团队背景?(CEO/COO/选品/运营)
4. 公司总人数?研发、运营、供应链各多少人?
5. 有没有外部投资人?投了哪几家?

### 🛒 二、产品与品类(5 题)

6. 核心产品是哪几个?客单价多少?
7. 品类毛利率大概多少?(3C 数码 40-60%,服装 50-70%)
8. SKU 总数?Top 10 SKU 占比?
9. 跟同行(对标公司)相比,差异化在哪里?
10. 新品规划?未来 12 个月上几个新品?

### 💰 三、财务与现金流(5 题)

11. 去年营收多少?今年预计多少?
12. 主要收款通道?(PingPong / WorldFirst / 连连 / Airwallex)
13. 平台收款流水多少?(比利润表更真实)
14. 经营性现金流是正还是负?
15. 净利率大概多少?(跨境电商净利 5-15% 是健康水平)

### 📦 四、渠道与运营(5 题)

16. Amazon 占比?TikTok Shop 占比?独立站占比?
17. 美国/欧洲/东南亚各占多少?
18. 海外仓分布?(FBA 仓 + 第三方仓)
19. 广告投入占比?(健康水平 10-20%)
20. 退货率多少?(品类差异大)

### ⚠️ 五、风险与合规(5 题)

21. 有没有被 Amazon 封号历史?原因?
22. 有没有收到过平台警告?(评论/合规/刷评)
23. 汇率怎么对冲?有没有做套保?
24. CE / FCC / FDA / EPR 等认证齐不齐?
25. VAT 税号有没有?(欧洲销售必备)

### 🤝 六、合作与诉求(5 题)

26. 目前在哪些银行有授信?贷款余额多少?
27. 现在的资金主要用途?(备货/营销/扩品类)
28. 未来 12 个月有没有大额支出?(海外仓建设/团队扩张)
29. 有没有融资规划?是债权还是股权?
30. "你们最希望银行提供什么产品?"(开放式)

## 关键信号判断

### ✅ 绿灯信号(值得深耕)

- 自有品牌 + 研发投入
- 多平台分散(Amazon < 70%)
- 收款流水稳定增长
- 净利率 > 10%
- 海外仓布局合理
- 合规完备(CE/FCC/VAT)
- 团队稳定 3 年以上
- 实控人无股权质押

### 🟡 黄灯信号(需要进一步尽调)

- 单一品类 > 80%
- 平台占比 70-90%
- 净利率 5-10%
- 退货率 10-20%
- 有收到过平台警告
- 实控人质押 30-50%

### 🔴 红灯信号(不建议介入)

- 单平台 100%
- 历史封号记录
- 净利率 < 3%
- 退货率 > 30%
- 合规缺失
- 大股东质押 > 50%
- 涉及刷评/违规运营

## 跨境电商特殊尽调要点

### 平台数据(必查)

1. **Amazon Brand Registry** 状态
2. **Amazon 店铺绩效** (ODR < 1%, Late Shipment Rate < 4%)
3. **BSR 排名** (Best Seller Rank)
4. **Review 评分** (健康 > 4.0)
5. **Review 增长曲线** (异常增长 = 刷评嫌疑)
6. **库存周转** (IPI 分数 > 400)

### 收款流水(必看)

1. **PingPong/连连/WF 月流水** (直接反映销售)
2. **提现频率** (资金紧张 = 频繁提现)
3. **多账户分散** (合规风险)
4. **汇率损失** (没有套保 = 利润侵蚀)

### 海外仓(必看)

1. **FBA 库存报表** (滞销库存 = 资金沉淀)
2. **第三方海外仓** (分布 + 利用率)
3. **库存周转天数** (健康 < 90 天)
4. **滞销 SKU 占比** (> 30% 风险)

### 合规(必查)

1. **CE / FCC / FDA 证书** (产品级)
2. **VAT 税号** (欧洲)
3. **EPR 注册** (欧盟生产者责任)
4. **CPSC** (美国消费品安全)
5. **品牌商标** (海外注册 + 海关备案)

## 不同细分赛道的特别关注点

### 3C 数码品牌

- 看专利布局(充电协议专利)
- 看 Amazon BSR 排名稳定性
- 看海外仓库存周转
- 关注兼容性认证(MFi/QC/PD)

### 智能家居品牌

- 看客单价($300-1000+)
- 看售后退货率
- 看品牌效应(社交媒体声量)
- 关注 Wi-Fi/蓝牙认证

### 便携储能品牌

- 看 UN38.3 认证(电池运输)
- 看功率/容量技术参数
- 看美国户外市场认知度
- 关注关税政策(美国对中国储能)

### 跨境电商代运营

- 看服务的品牌商数量和质量
- 看抽佣比例(10-20% 健康)
- 看代运营 vs 自营品牌占比
- 关注客户流失率

### 跨境 SaaS 服务商

- 看 ARR / 续约率(> 80% 健康)
- 看大客户集中度
- 看订阅 vs 一次性收费
- 关注客户终身价值(LTV)

## 实战经验

### 拜访技巧

1. **看 Amazon 店铺比问老板更准**: 老板会美化,数据不会
2. **问 PingPong 流水比问营收更准**: 老板会避税,流水不会
3. **看仓库比看办公室更准**: 办公室豪华≠公司健康
4. **问物流商比问老板更准**: 物流商知道真实发货量
5. **看团队氛围比看简历更准**: 高压 + 996 + 频繁加班 = 现金流紧张

### 识别谎言/夸大

- 流水对不上:问 PingPong/连连月提现金额
- 销量对不上:问 BSR 排名 + 评论数 + 上架时间
- 团队对不上:看工位数 + 招聘数据 + 离职率
- 库存对不上:问 FBA 库存报表

### 谈判要点

- **不要现场承诺**:所有授信走流程
- **不要承诺汇率优惠**:外汇套保有标准报价
- **要承诺时效**:7 天内给方案,15 天内给反馈
- **要拿到关键人**:老板 + 财务 + 运营的联系方式
