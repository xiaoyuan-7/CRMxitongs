# 深圳供应链生态 · 银行对公研究

> **核心洞察**: 客户经理看了太多"前沿产业"故事,但**深圳真正的银行金矿在供应链**——链主企业链上 10000+ 家小微,绝大多数未上市、未被覆盖
> **目标**: 系统化识别深圳供应链生态,挖掘"链主 + 链上小微"的银行机会
> **核心打法**: 链主确权 + 链上小微授信 = **供应链金融**

---

## 为什么深圳供应链是"被低估的金矿"

### 三个反常识

1. **链主链上小微 = 优质资产** — 这些公司是**已经被验证过的供应商**(能进比亚迪/华为链就说明质量 OK),比盲目找小微效率高 10 倍
2. **深圳供应链 = 10000+ 家银行未覆盖客户** — 大多数供应商是未上市小微,银行传统渠道看不到
3. **链主确权 = 风险可控** — 应收账款基于真实交易,坏账率远低于普通小微贷款

### 深圳供应链的核心优势

| 优势 | 说明 |
|---|---|
| 配套密度 | 1 公里内可找全 PCB + PCBA + 模具 + 注塑 + 钣金 + 包装 |
| 物流优势 | 深圳港 + 香港机场,头程物流全国最快 |
| 人才密集 | 电子制造业工人/工程师聚集 |
| 政策支持 | 深圳"工业上楼" + 智能制造扶持 |

## 银行介入的"3 层打法"

### 第一层:链主直接授信(谨慎)

**特点**:链主本身规模大、议价权强
**风险**:银行被边缘化(用自有资金 + 自有供应链金融)
**建议**:**谨慎介入**,除非是 IPO/可转债/并购等大单

### 第二层:链上 Tier 1-2 供应商(主攻 ⭐⭐⭐⭐⭐)

**特点**:链主确权,应收账款真实
**银行产品**:
- 应收账款融资(基于链主合同)
- 订单贷(基于链主订单)
- 供应链金融(链主推荐)

**目标客户**:
- 比亚迪链上 Tier 1-2 供应商(500-1000 家)
- 华为链上 Tier 1-2 供应商(1000+ 家)
- 大疆链上 Tier 1-2 供应商(300+ 家)

### 第三层:基础供应链(慎入)

**特点**:Tier 3-5,无链主确权
**风险**:质量参差不齐
**建议**:**慎入**,仅做"有链主推荐"或"有多年合作历史"的客户

## 与现有赛道的关系

- **新能源/储能赛道**:覆盖了"动力电池 + 储能"产业链
- **机器人/AI 赛道**:覆盖了"核心部件 + 本体"
- **医疗器械赛道**:覆盖了"IVD + 设备 + 高耗"
- **跨境电商赛道**:覆盖了"品牌出海"
- **供应链专题**:**覆盖了"底层制造"(PCB/PCBA/模具/注塑/钣金)**——其他赛道都依赖这些底层

**供应链 = 其他 4 个赛道的"共同底层"**
