## 🥇 第一推荐:医疗器械(深圳最适合对公深耕)

- **深圳是全国医疗器械产业核心城市**(产值仅次于苏州,迈瑞、华大、新产业总部都在深圳)
- **银行最容易介入**: 医疗设备可抵押、医院应收账款可融资(账期 180-360 天反而是融资机会)
- **资产可见**: 注册证、专利、医疗设备、销售合同 — 尽调维度全
- **抗周期**: 医疗是刚需,不受经济周期影响
- **政策持续**: 坪山生物医药谷、深圳医疗器械产业政策

**细分方向**: IVD / 体外诊断、医疗设备、高值耗材
**典型客户池**: 迈瑞供应链上下游 / 华大基因上下游 / 坪山生物医药产业基地
**风险点**: 集采降价 / 注册证周期长 / 监管严格

## 🥈 第二推荐:新能源/储能(政策红利 + 资产重)

- 深圳新能源重镇: 比亚迪总部 / 华为数字能源 / 欣旺达 / 贝特瑞
- **新型储能是国家战略**,政策资金持续投入
- **资产可见**: 设备、厂房、应收(电网/工商业用户)
- 单笔业务量大,客户经理投入产出比高

**细分方向**: 储能系统集成 / 储能电池 / 储能逆变器
**风险点**: 产能过剩 / 周期波动 / 价格战

## 🥉 第三推荐:机器人 + AI 应用(深圳未来 10 年主线)

- 深圳是全国机器人产业第一: 大疆 / 优必选 / 越疆 / 思灵
- AI 应用爆发: 腾讯 / 华为 + 一批垂直 AI 公司
- 长线价值: 5-10 年出来的就是独角兽

**风险点**: 轻资产银行难介入 / 商业化周期长 / 技术变化快
**对公角色**: 不做主力客户池,做**长期跟踪 + 早期介入**

## 推荐组合

- **🎯 稳健组合(首选)**: 医疗器械 + 新能源/储能
- **🎯 长线组合(进阶)**: 医疗器械 + 机器人/AI
- **⚠️ 不推荐组合**: 机器人 + AI 应用(都是轻资产,银行难做)

## 起步动作

1. 下载工信部专精特新"小巨人"名单(Excel 全量公开)
2. 加入深圳市医疗器械行业协会 / 深圳市新能源行业协会
3. 园区招商办拜访: 坪山生物医药产业基地 / 宝安光明储能产业园

## 最终建议

80% 精力放**医疗器械**,20% 用来**跟踪机器人/AI**(长线).
医疗器械 6-12 个月能见到成果;机器人/AI 12-24 个月才能开花.
**先打粮草,再押注未来.**
