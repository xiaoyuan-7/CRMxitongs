# 医疗器械 · 评分模型

> **目标**: 1-100 分量化评估医疗器械客户的信贷价值
> **用途**: A/B/C 分层 + 决策矩阵 + 一票否决

---

## 一、5 大评分维度(总分 100)

### 维度 1:技术壁垒(20 分)

| 子项 | 满分 | 评分标准 |
|---|---|---|
| 发明专利数 | 8 分 | ≥30 项 8 分 / 10-30 项 5 分 / <10 项 2 分 |
| 注册证数量(III 类) | 6 分 | ≥10 张 6 分 / 3-10 张 4 分 / <3 张 2 分 |
| 研发投入占比 | 4 分 | ≥15% 4 分 / 8-15% 2 分 / <8% 0 分 |
| 细分赛道排名 | 2 分 | Top 3 2 分 / Top 10 1 分 / 其他 0 分 |

**打分要点**:
- 发明专利要看质量(发明 vs 实用新型)+ 持续性(最近 1 年新增)
- 注册证要看 III 类(II 类难度低)
- 研发投入要看绝对值,不要只看占比(营收 1000 万 vs 1 亿的 15% 差 10 倍)

### 维度 2:财务健康(25 分)

| 子项 | 满分 | 评分标准 |
|---|---|---|
| 营收规模 | 8 分 | ≥10 亿 8 分 / 1-10 亿 5 分 / <1 亿 2 分 |
| 营收增长率 | 5 分 | ≥30% 5 分 / 15-30% 3 分 / <15% 1 分 |
| 毛利率 | 6 分 | ≥60% 6 分 / 40-60% 4 分 / <40% 2 分 |
| 经营性现金流 | 6 分 | 连续 2 年正 6 分 / 1 年正 3 分 / 连续负 0 分 |

**打分要点**:
- 医疗器械毛利率普遍高(50-70%),低于 40% 要警惕
- 经营现金流为负的科技小微 = 高风险
- 应收账款周期 > 360 天 = 现金流压力

### 维度 3:客户结构(20 分)

| 子项 | 满分 | 评分标准 |
|---|---|---|
| 前五大客户占比 | 8 分 | <30% 8 分 / 30-50% 5 分 / 50-70% 2 分 / >70% 0 分 |
| 客户类型 | 6 分 | 海外品牌客户 6 分 / 三甲医院 4 分 / 经销商 2 分 |
| 应收账款周转天数 | 6 分 | <180 天 6 分 / 180-360 天 4 分 / >360 天 1 分 |

**打分要点**:
- 经销商占比 > 50% 要警惕(终端销售数据不可见)
- 应收账款周期长 = 资金链压力大
- 单客户依赖 > 70% = 一票否决

### 维度 4:团队与治理(15 分)

| 子项 | 满分 | 评分标准 |
|---|---|---|
| 创始人背景 | 5 分 | 行业 10+ 年 5 分 / 跨行业 2 分 / 首次创业 0 分 |
| 核心团队稳定性 | 4 分 | 5 年以上稳定 4 分 / 有流失 2 分 / 频繁变动 0 分 |
| 股权结构清晰 | 3 分 | 实控人 >50% 3 分 / 30-50% 1 分 / <30% 0 分 |
| 外部投资人背书 | 3 分 | 头部 VC 3 分 / 普通 VC 1 分 / 无 0 分 |

**打分要点**:
- 创始人行业经验比学历更重要
- 核心技术人员(CTO/首席科学家)稳定性
- 股权分散可能引发控制权之争

### 维度 5:政策与行业(20 分)

| 子项 | 满分 | 评分标准 |
|---|---|---|
| 细分赛道政策风险 | 8 分 | 政策友好 8 分 / 中性 4 分 / 集采重点 0 分 |
| 国产替代逻辑 | 6 分 | 替代空间大 6 分 / 中等 3 分 / 已饱和 1 分 |
| 行业增速 | 6 分 | ≥20% 6 分 / 10-20% 4 分 / <10% 2 分 |

**打分要点**:
- 集采重点品类(IVD 化学发光、骨科、心脏支架、眼科)= 减分
- 国产替代空间(高端影像、手术机器人、心脏介入) = 加分
- 行业增速看 3-5 年趋势

## 二、一票否决红线(任一触发 = 0 分)

### 🔴 红线清单(不碰)

| 红线 | 说明 |
|---|---|
| 单客户依赖 > 70% | 失去大客户 = 公司死亡 |
| 经营现金流连续 2 年为负 | 自我造血能力缺失 |
| 大股东股权质押 > 50% | 资金链紧张 + 实控人风险 |
| 关联交易 > 营收 30% | 利益输送嫌疑 |
| 研发投入资本化率 > 50% | 财务洗澡嫌疑 |
| 重大医疗事故 / NMPA 飞检不通过 | 监管风险 |
| 实控人失信 / 涉诉 | 一票否决 |
| 集采重点品类 + 占比 > 50% | 政策风险致命 |

## 三、A/B/C/D 分层决策

### A 类(90-100 分):重点跟进

- 7 天内提交授信方案初稿
- 优先级产品匹配:全产品线
- 联合尽调 + 内部白名单
- 季度跟踪 + 高管定期对接

### B+ 类(75-89 分):积极培育

- 14 天内提交授信方案
- 主流产品(流水贷 + 应收 + 设备抵押)
- 半年跟踪 + 关键节点对接
- 培养 12 个月,争取升级 A 类

### B 类(60-74 分):观察培育

- 30 天内提交初步方案
- 单一产品(流水贷或设备抵押)
- 年跟踪 + 重要节点对接
- 条件改善可升级

### C 类(45-59 分):暂缓

- 暂不主动授信
- 季度简单回访
- 等待条件改善

### D 类(<45 分):不建议介入

- 直接放弃,不留面子
- 不投入后续精力

---

## 四、评分实操流程

### 第 1 步:红线检查(5 分钟)

✅ 全部通过 → 进入评分
❌ 任一触发 → 直接 D 类

### 第 2 步:评分卡填写(20 分钟)

- 每个维度对照子项打分
- 不确定项标"?"(后续补尽调)

### 第 3 步:总分计算 + 分层(5 分钟)

- 总分 = 5 维度之和
- 对照分层标准定 A/B/C/D
- 记录主要拉分项

### 第 4 步:输出评分报告(30 分钟)

```
客户: XX 公司
评分: XX 分
分层: A/B/C/D
主要加分项: ...
主要减分项: ...
授信建议: ...
跟进动作: ...
```

## 五、评分模板(Excel 化)

### Excel 列结构

| 列 | 内容 |
|---|---|
| A | 客户名称 |
| B | 拜访日期 |
| C | 维度 1:技术壁垒(0-20) |
| D | 维度 2:财务健康(0-25) |
| E | 维度 3:客户结构(0-20) |
| F | 维度 4:团队治理(0-15) |
| G | 维度 5:政策行业(0-20) |
| H | 总分 |
| I | 分层 |
| J | 一票否决触发项 |
| K | 主要加分项 |
| L | 主要减分项 |
| M | 授信建议 |
| N | 跟进负责人 |
| O | 下次拜访日期 |

### Excel 条件格式

- 总分 ≥ 90:绿色(重点跟进)
- 总分 75-89:浅绿(积极培育)
- 总分 60-74:黄色(观察培育)
- 总分 45-59:橙色(暂缓)
- 总分 < 45:红色(放弃)
- 一票否决:整行红色

## 六、评分校准

### 每月回顾

- A 类客户是否真的优质?(看后续贷款是否按时还)
- B+ 类升级为 A 的比例(目标 30%+)
- C 类改善并升级的比例(目标 10%+)
- D 类是否真的不该碰?

### 季度校准

- 评分标准是否需要调整?
- 红线是否需要增减?
- 维度权重是否需要调整?

### 复盘机制

- 客户违约 → 复盘评分哪里漏了
- 客户超预期 → 复盘评分哪里过严
- 季度汇总,迭代模型

## 七、案例演练

### 案例 1:深圳某 IVD 公司

| 维度 | 子项 | 评分 | 备注 |
|---|---|---|---|
| 技术 | 发明专利 25 项 + III 类 5 张 + 研发占比 12% + 细分 Top 10 | 15/20 | 技术中上 |
| 财务 | 营收 3 亿 + 增长 25% + 毛利 65% + 现金流正 | 19/25 | 财务健康 |
| 客户 | 前五客户 45% + 公立医院为主 + 应收回款 220 天 | 14/20 | 客户分散 |
| 团队 | 创始 12 年 + 核心稳定 + 实控人 55% + 高瓴投资 | 14/15 | 团队强 |
| 政策 | 化学发光已集采(减分)+ 国产替代中 + 行业 15% | 9/20 | 集采风险 |
| **总分** | | **71/100** | **B 类** |

**结论**: 政策风险拉分,但其他维度优秀. 建议:
- B 类培育
- 重点产品:流水贷 + 应收 + 知识产权质押
- 季度跟踪 + 关注集采后续影响

### 案例 2:深圳某医疗影像 AI 公司

| 维度 | 子项 | 评分 | 备注 |
|---|---|---|---|
| 技术 | 发明专利 15 项 + 无 III 类(算法服务) + 研发占比 60% + AI 影像 Top 5 | 14/20 | 技术强 |
| 财务 | 营收 5000 万 + 增长 80% + 毛利 70% + 现金流负 | 10/25 | 高速增长但亏损 |
| 客户 | 前五客户 70% + 三甲医院 + 应收回款 360 天 | 9/20 | 客户集中 |
| 团队 | 创始 8 年 + 核心稳定 + 实控人 40% + 红杉投资 | 11/15 | 团队强 |
| 政策 | AI 医疗鼓励 + 国产替代大 + 行业 30% | 16/20 | 政策友好 |
| **总分** | | **60/100** | **B 类** |

**结论**: 高速增长 + 政策友好,但现金流和客户集中度是隐患. 建议:
- B 类观察
- 暂不主动授信,等现金流改善
- 半年后再评估
