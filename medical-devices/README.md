# 医疗器械 · 银行对公行业研究

> **目标**: 6-12 个月成为深圳医疗器械赛道的银行对公专家
> **细分聚焦**: IVD / 体外诊断、医疗设备、高值耗材
> **切入点**: 坪山生物医药产业基地 + 迈瑞/华大供应链上下游

## 为什么是医疗器械

| 维度 | 评分 | 说明 |
|---|---|---|
| 深圳产业聚集度 | ⭐⭐⭐⭐⭐ | 全国第二(迈瑞/华大/新产业总部) |
| 银行介入难度 | ⭐⭐⭐ 易 | 设备可抵押 + 医院应收账款可融资 |
| 抗周期 | ⭐⭐⭐⭐⭐ | 医疗刚需,不受经济周期影响 |
| 政策持续性 | ⭐⭐⭐⭐⭐ | 国家战略 + 深圳政策叠加 |
| 客户质量 | ⭐⭐⭐⭐⭐ | 壁垒高、不易被颠覆 |
| 与你存量客户协同 | ⭐⭐⭐⭐ | 制造业客户可升级为科技升级方案 |

## 与银行的契合点

| 银行产品 | 适用场景 |
|---|---|
| 设备抵押贷 | 医疗设备生产厂(CT/MRI/超声) |
| 应收账款融资 | 医院/经销商长账期(180-360 天) |
| 知识产权质押贷 | 发明专利 + 注册证 |
| 科技 e 贷 | 高新技术企业 + 研发投入 |
| 投联贷 | VC/PE 已投企业 + 上市预期 |
| 订单贷 | 政府采购 + 大型医院中标 |

## 风险预警

- **集采降价**: IVD / 骨科 / 心血管耗材重点关注(已有先例)
- **注册证延期**: NMPA 注册周期 2-3 年,延期影响营收
- **客户集中度**: 部分企业单家医院或经销商占比 > 50%
- **应收账款**: 医院端账期长,需关注融资能力
- **研发资本化**: 部分企业美化报表
