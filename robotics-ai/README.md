# 机器人/AI · 银行对公行业研究

> **目标**: 6-12 个月成为深圳机器人/AI 赛道的银行对公专家
> **细分聚焦**: 人形机器人 / 协作机器人 / 服务机器人 / 医疗 AI
> **切入点**: 南山(优必选/大族机器人/越疆)+ 宝安(普渡/云鲸)+ 龙岗(部分)
> **重要警告**: 机器人/AI 是前沿长线赛道,商业化路径不清,银行介入要谨慎

## 关键判断(银行视角)

- **不是所有机器人都有商业化**——人形机器人 95% 在研发/概念阶段
- **估值泡沫风险显著**——Figure AI 估值 26 亿美元但没量产
- **银行介入策略 = 投贷联动为主**——不是直接授信
- **关注"商业化阶段"比"技术强"更重要**——已盈利 > 商业化中 > 技术研发
- **深圳优势在协作/服务机器人**——不是人形(北京/杭州/上海主导)

## 银行介入的"3 个层次"

### 第一层:已商业化(主攻)
- 服务机器人(扫地/配送) → 订单贷
- AGV/AMR → 项目贷
- 协作机器人(头部) → 投贷联动

### 第二层:商业化中(谨慎)
- 协作机器人(中小) → 知识产权质押
- 医疗 AI(已拿证) → 投贷联动 + 知识产权质押
- 服务机器人(细分场景) → 订单贷

### 第三层:技术研发(慎入)
- 人形机器人 → 仅投贷联动
- 医疗 AI(未拿证) → 不介入
- 通用大模型 → 不介入
