## 一、机器人基础术语(20 个)

### 1.1 机器人定义类

| 术语 | 解释 | 银行启示 |
|---|---|---|
| **机器人** | 物理实体、可执行任务的设备 | 看得见摸得着 |
| **AI(人工智能)** | 算法 + 数据 + 算力 | 软件形态 |
| **具身智能(Embodied AI)** | AI + 机器人 = 智能物理实体 | **2024 国家战略** |
| **AGI(通用人工智能)** | 通用任务 AI | 长线方向 |
| **机器学习** | AI 子领域,从数据学习 | 算法核心 |
| **深度学习** | 神经网络 + 大数据 | 当前主流 |
| **大模型(LLM)** | 大语言模型 | GPT/Claude/文心 |
| **VLA 模型** | Vision-Language-Action | **机器人专用大模型** |
| **多模态** | 视觉+语言+听觉融合 | AI 未来方向 |
| **端到端模型** | 输入→输出,无中间模块 | Tesla FSD 路线 |

### 1.2 机器人类型类

| 术语 | 解释 | 银行启示 |
|---|---|---|
| **工业机器人** | 6 轴机械臂 + 控制器,工厂自动化 | 成熟,头部已上市 |
| **协作机器人(cobot)** | 力矩传感器 + 安全控制,人机协作 | 深圳强 |
| **人形机器人** | 双足 + 灵巧手 + VLA | 2024-2027 突破期 |
| **AGV/AMR** | 自动导引车/自主移动机器人 | 物流仓储 |
| **服务机器人** | 视觉 + 语音 + 移动底盘 | 餐饮/扫地/陪伴 |
| **医疗机器人** | 高精度机械臂 + 影像 | 手术/康复 |
| **特种机器人** | 巡检/消防/水下 | 行业应用 |
| **仿生机器人** | 模仿生物(狗/鱼/鸟) | 宇树科技等 |

### 1.3 机器人核心技术类

| 术语 | 解释 | 银行启示 |
|---|---|---|

## 五、商业与财务术语(20 个)

### 5.1 商业化阶段类

| 术语 | 解释 | 银行启示 |
|---|---|---|
| **商业化阶段** | 技术研发/商业化中/已盈利 | **银行介入核心判断** |
| **技术研发** | 烧钱,靠 VC 续命 | 仅投贷联动 |
| **商业化中** | 有收入但亏损 | 投贷联动 + 知识产权质押 |
| **已盈利** | 稳定现金流 | 全产品线 |
| **量产能力** | 大规模生产 | 商业化验证 |
| **demo 视频** | 演示视频 ≠ 量产 | 警惕 PPT 估值 |
| **PPT 估值** | 没收入只有概念 | 慎入 |
| **现金储备** | 现金 / 月度运营 | 亏损型企业关键 |

### 5.2 融资类

| 术语 | 解释 | 银行启示 |
|---|---|---|
| **投贷联动** | 银行贷款 + VC 投资联动 | 早期企业主推 |
| **估值** | 企业市场价值 | 警惕泡沫 |
| **估值/收入比** | PS 估值倍数 | >50 = 泡沫 |
| **Pre-IPO 轮** | 上市前最后一轮融资 | 接近上市 |
| **A/B/C/D 轮** | VC 投资阶段 | 越早期风险越高 |
| **战略融资** | 产业资本投资 | 资源 + 资本 |
| **政府引导基金** | 政府投资基金 | 政策导向 |

### 5.3 银行产品类

| 术语 | 解释 | 银行启示 |
|---|---|---|
| **订单贷** | 基于真实订单的贷款 | 已商业化企业 |
| **投贷联动** | 银行贷款 + VC 投资联动 | 早期企业 |
| **知识产权质押** | 以专利/商标为质押 | 早期企业 |
| **应收账款融资** | 以应收账款为质押 | 出海企业 |
| **出口信用证** | 银行信用担保的出口结算 | 出海企业 |
| **项目贷** | 以项目现金流为还款 | AGV/AMR |
| **供应链金融** | 以核心企业信用为支持 | 链上小微 |
