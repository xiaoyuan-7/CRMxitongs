## CRM融合攻坚页面修复 - 逐层变窄Bug

### 问题描述
融合攻坚标签页中，不同业务板块（B2C保险→B2C小微贷→B2C百人代发等）的行宽逐级收窄。

### 根因
`.fusion-table-fix * { width: 900px !important; max-width: 900px !important; min-width: 900px !important; box-sizing: border-box; }`
这条CSS规则将所有 fusion-table-fix 内部元素强制锁定为900px，与外层容器冲突，导致列宽计算错误。

### 修复方案（已实施）
1. **删除** `.fusion-table-fix * { width: 900px !important; ... }` 全局强制规则
2. **fusionTab**: 改回 `width:100%`（之前被锁死900px）
3. **fusionListHeader**: 改为 `grid-template-columns` + `min-width:0`（不再固定900px）
4. **fusion-row**: 保持grid布局 + `width:100%`
5. **fusion-detail**: `width:100%` + `display:block`
6. **fusionContent**: `width:100%` + `overflow:visible`
7. **移除** `overflow-x:auto` 和 `max-height:70vh`

`/home/admin/.openclaw/workspace/crm-system/frontend-simple/index.html`
