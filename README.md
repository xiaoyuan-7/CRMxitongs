## 🔍 核心方法论

### 信息源分层

1. **政府名单**(免费权威): 工信部专精特新 / 各地科技局雏鹰瞪羚
2. **VC/PE 投资清单**: 投中网 / IT 桔子 / 36 氪
3. **园区/孵化器**: 中关村 / 张江 / 深圳湾 / 坪山 / 苏州工业园
4. **招投标数据**: 中国招标投标公共服务平台 / 剑鱼标讯
5. **人才/专利**: 拉勾 / 国家知识产权局
6. **一手实战**: 客户拜访 / 工厂考察 / 客户访谈

### 评估维度(对公尽调)

- **技术壁垒**: 发明专利数 / 研发投入占比 / 细分赛道排名
- **客户结构**: 前五大客户占比 / 续约率 / 政企民企比例
- **现金流**: 经营性现金流 / 毛利率 / 应收账款周转天数
- **应收账款**: 账期 / 坏账计提
- **团队**: 创始人背景 / 核心技术人员稳定性 / 股权激励

### 一票否决红线

- 客户集中度 > 70%
- 大股东股权质押 > 50%
- 关联交易 > 营收 30%
- 研发投入资本化率 > 50%
