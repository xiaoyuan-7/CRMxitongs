# 新能源/储能 · 银行对公行业研究

> **目标**: 6-12 个月成为深圳新能源/储能赛道的银行对公专家
> **细分聚焦**: 储能(便携/家用/工商业/电网侧) > 动力电池(乘用车/两轮) > 充电桩/换电 > 光伏 > 氢能
> **切入点**: 坪山比亚迪 + 光明储能产业基地 + 宝安便携储能集群

## 为什么是新能源/储能

| 维度 | 评分 | 说明 |
|---|---|---|
| 深圳产业聚集度 | ⭐⭐⭐⭐⭐ | 比亚迪总部+正浩 EcoFlow+欣旺达+科华数能,产业链完整 |
| 银行介入难度 | ⭐⭐⭐ 中 | 重资产+应收长(电网 6-12 个月),需要项目贷+应收账款产品 |
| 抗周期 | ⭐⭐⭐ | 受锂价/政策/海外贸易影响波动大,非典型抗周期 |
| 政策持续性 | ⭐⭐⭐⭐⭐ | 双碳战略+新型储能政策+电力市场化,政策红利持续 5-10 年 |
| 客户质量 | ⭐⭐⭐⭐ | 头部优质(比亚迪/华为数字能源),但产能过剩期中小厂承压 |
| 与你存量客户协同 | ⭐⭐⭐⭐ | 制造业/外贸/科技公司客户,均可升级为新能源方案 |

## 关键判断(银行视角)

- **不是所有新能源都赚钱**:储能行业 2024 Q1 头部企业毛利率 -3%,产能过剩已经开始洗牌
- **深圳的核心优势在便携储能+工商业储能**:不是动力电池(宁德时代主导),不是光伏(江浙主导)
- **便携储能出海是高增长赛道**:EcoFlow(正浩)/Jackery(华宝)/Anker SOLIX 三家深圳公司瓜分全球 50%+ 份额
- **比亚迪是超级客户但银行介入难**:垂直整合+自己供应链,银行只能做"链上小微"
- **银行甜蜜区是工商业储能集成商+便携储能品牌商+上游材料供应商**

## 切入点建议

### 第一批客户池(本周)

1. **坪山比亚迪供应链上下游**(电池材料/结构件/PACK 厂)
2. **光明储能产业基地入驻企业**(储能集成商/PCS/BMS 厂)
3. **宝安便携储能集群**(正浩 EcoFlow/华宝新能上下游)

### 必拜访的 4 个聚集区

1. **坪山**(比亚迪总部+欣旺达+贝特瑞)
2. **光明**(储能产业基地+科华数能)
3. **宝安**(便携储能集群+科列技术)
4. **龙华/龙岗**(充电桩/换电企业)

### 必加入的 3 个协会

- **中关村储能产业技术联盟(CNESA)** — 储能行业最权威
- 深圳市新能源行业协会
- 中国化学与物理电源行业协会

### 必参加的 3 个展会

- **SNEC 储能展**(上海,每年 11 月) — 全球最大储能展
- **CIBF 中国国际电池展**(深圳,每年 4-5 月) — 电池行业风向标
- **高工储能年会**(广州/深圳) — 行业深度交流

## 风险预警(必看)

- **产能过剩**:2024 储能/动力电池行业洗牌,部分企业 Q1-Q2 亏损
- **锂价波动**:碳酸锂从 60 万/吨跌到 10 万/吨(跌 80%),存货跌价风险
- **美国 IRA**:中国电池 2024 后失去补贴,影响出口
- **政策退坡**:储能补贴/充电桩补贴政策窗口期变化
- **技术路线风险**:磷酸铁锂 vs 三元 vs 钠离子路线选择错误会致命
- **应收账款长**:电网/工商业客户账期 6-12 个月,资金压力大
- **海外贸易壁垒**:欧盟反补贴、美国 301 关税、IRA 本土化
