# 新能源/储能 · 术语词典

> **用途**: 客户经理拜访前速查,确保不被识破
> **基准日**: 2025 年 12 月,需要持续更新
> **覆盖**: 储能/电池/政策/财务 100+ 核心术语

---

## 一、储能基础术语(20 个)

### 1.1 储能定义类

| 术语 | 解释 | 银行启示 |
|---|---|---|
| **储能** | 把电能/热能/动能储存起来,需要时释放 | 储能 = 电力系统的"水库" |
| **储能电站** | 集中式储能设施,MW 级以上 | 项目贷主要标的 |
| **分布式储能** | 工厂/园区/家庭的小型储能 | 设备租赁 + 项目贷 |
| **用户侧储能** | 工厂/商业体/家庭安装的储能 | 工商业峰谷套利 |
| **电网侧储能** | 电网公司投资的储能 | 国电/南网系统内 |
| **电源侧储能** | 新能源电站配套储能 | 强配政策,大单 |
| **共享储能** | 多方共同投资的储能电站 | 第三方运营,新模式 |
| **虚拟电厂(VPP)** | 通过软件聚合分布式能源 | 储能 + 数字化新方向 |

### 1.2 储能技术类

| 术语 | 解释 | 银行启示 |
|---|---|---|
| **BMS(电池管理)** | 监控电池状态(SoC/SoH)、保护、热管理 | 中等壁垒,深圳有玩家 |
| **PCS(储能变流器)** | 直流/交流转换、电网同步 | 高壁垒,阳光/华为/科华 |
| **EMS(能量管理)** | 调度优化、收益最大化 | 最高壁垒,算法驱动 |
| **SoC(State of Charge)** | 电池剩余电量百分比 | BMS 核心指标 |
| **SoH(State of Health)** | 电池健康度,0-100% | 电池寿命关键 |
| **EPC(设计采购施工)** | 工程总包,设计+设备+施工 | 阳光/宁德/比亚迪 |
| **SoC 估算精度** | BMS 估算电池剩余电量的误差 | 1-3% 算优秀 |
| **循环次数** | 电池完整充放电的次数 | 储能 6000-10000 次 |

### 1.3 储能商业模式类

| 术语 | 解释 | 银行启示 |
|---|---|---|
| **峰谷套利** | 低电价充电 + 高电价放电 | 工商业储能核心 IRR |
| **需量管理** | 降低最高用电功率,节省基本电费 | 工商业储能收益点 |
| **容量电价** | 电网给储能的容量补偿 | 2024 政策红利 |
| **调频** | 维持电网频率稳定 | 电网侧储能业务 |
| **调峰** | 平衡电网峰谷差 | 电网侧储能业务 |
| **需量响应** | 紧急情况下减少用电 | 用户侧储能业务 |

## 二、电池技术术语(25 个)

### 2.1 电池类型类

| 术语 | 解释 | 银行启示 |
|---|---|---|
| **磷酸铁锂(LFP)** | 安全性高、循环长,储能用主流 | 储能首选,正极材料主流 |
| **三元(NCM/NCA)** | 能量密度高,动力电池用 | 安全性差,谨慎授信 |
| **钠离子电池** | 成本低,2024-2025 量产 | 新技术,投贷联动 |
| **半固态电池** | 安全性提升,2025 量产 | 新技术,投贷联动 |
| **全固态电池** | 下一代电池,2027+ 量产 | 长线跟踪 |
| **钒液流电池** | 寿命长(20 年),适合长时长 | 电网侧,大连融科 |
| **锂硫电池** | 理论能量密度高,未商业化 | 实验室阶段 |
| **铅酸电池** | 传统电池,逐步淘汰 | 不介入 |

### 2.2 电池组件类

| 术语 | 解释 | 银行启示 |
|---|---|---|
| **电芯** | 电池最小单元 | 宁德/比亚迪/亿纬 |
| **电池模组** | 多个电芯组成的小单元 | PACK 厂 |
| **PACK(电池包)** | 多个模组+外壳+BMS | 集成度最高,价值最大 |
| **正极材料** | 决定电池能量密度 | 湖南裕能/德方纳米 |
| **负极材料** | 决定电池循环寿命 | 贝特瑞(深圳坪山) |
| **隔膜** | 隔离正负极,关键安全件 | 恩捷/星源材质(深圳光明) |
| **电解液** | 离子传导媒介 | 天赐/新宙邦(深圳) |
| **铜箔/铝箔** | 集流体 | 嘉元科技(深圳) |
| **六氟磷酸锂** | 电解液核心溶质 | 多氟多/天赐 |

### 2.3 电池参数类

| 术语 | 解释 | 银行启示 |
|---|---|---|
| **能量密度** | 单位重量/体积的电量(Wh/kg) | 动力电池关键指标 |
| **充放电效率** | 释放能量/充入能量 | 储能 88-92% |
| **循环寿命** | 电池完整充放电的次数 | 储能 6000-10000 次 |
| **日历寿命** | 电池使用年限(无论用没用) | 储能 10-15 年 |
| **倍率(C-rate)** | 充放电速度倍率 | 1C = 1 小时充满 |
| **DoD(放电深度)** | 每次放出电量的百分比 | 储能 80-90% |
| **热失控** | 电池内部温度失控,可能爆炸 | 储能最大安全风险 |

## 三、政策术语(20 个)

### 3.1 国家政策类

| 术语 | 解释 | 银行启示 |
|---|---|---|
| **新型储能** | 除抽水蓄能外的储能技术 | 政策核心词 |
| **"十四五"新型储能发展实施方案** | 2022 年发布,2025 年装机 30GW 目标 | 行业最关键政策 |
| **新型电力系统** | 新型电源 + 储能 + 数字化电网 | 2024 政策方向 |
| **容量电价** | 给储能容量补偿的电价 | 2024-2025 红利 |
| **电力现货市场** | 实时电价交易市场 | 储能收益模式 |
| **虚拟电厂** | 聚合分布式资源的电厂 | 2025-2027 红利 |

### 3.2 海外政策类

| 术语 | 解释 | 银行启示 |
|---|---|---|
| **IRA(美国通胀削减法案)** | 美国 2022 年法案,补贴本土制造 | 中国电池 2024 后失去补贴 |
| **FEOC(外国关注实体)** | IRA 中的限制条款 | 中国企业受影响 |
| **CBAM(欧盟碳关税)** | 欧盟 2025 实施,征碳排放费 | 出口欧洲成本上升 20-30% |
| **301 关税** | 美国对中国部分产品加征 25% 关税 | 影响储能出口 |
| **NPE(美国非政策实体)** | 类似 FEOC,影响 IRA 补贴 | 2024-2025 关注 |
| **欧洲电池法规** | 欧盟 2023 实施,要求碳足迹 | 出口门槛提升 |

### 3.3 地方政策类

| 术语 | 解释 | 银行启示 |
|---|---|---|
| **光明储能产业政策** | 深圳光明区储能扶持 | 项目落地补贴 |
| **坪山储能产业政策** | 深圳坪山区储能扶持 | 比亚迪链上企业 |

## 四、财务与业务术语(20 个)

### 4.1 财务指标类

| 术语 | 解释 | 银行启示 |
|---|---|---|
| **毛利率** | (营收-成本)/营收 | 储能品牌商 40%+ |
| **应收账款周转** | 营收/平均应收账款 | 储能 90-180 天 |
| **存货周转** | 成本/平均存货 | 储能 90-180 天 |
| **研发资本化** | 研发支出计入无形资产 | 警戒线 70% |
| **IRR(内部收益率)** | 项目投资收益 | 工商业储能 8-12% |
| **ROE(净资产收益率)** | 净利润/净资产 | 头部储能 15-25% |

### 4.2 银行产品类

| 术语 | 解释 | 银行启示 |
|---|---|---|
| **项目贷** | 以项目现金流为还款来源的贷款 | 工商业储能主战场 |
| **订单贷** | 以真实订单为抵押的贷款 | 便携储能/电网订单 |
| **应收账款融资** | 以应收账款为质押的贷款 | 工商业储能关键 |
| **供应链金融** | 以核心企业信用为支持的贷款 | 比亚迪/宁德链上 |
| **投贷联动** | 银行贷款 + VC 投资联动 | 储能早期小微 |
| **知识产权质押** | 以专利/商标为质押 | BMS/EMS 算法专利 |
| **出口信用证** | 银行信用担保的出口结算 | 便携储能出海 |

### 4.3 储能业务模式类

| 术语 | 解释 | 银行启示 |
|---|---|---|
| **峰谷电价差** | 高峰电价 - 低谷电价 | 工商业储能 IRR 核心 |
| **容量补偿** | 电网给储能容量的补偿 | 2024-2025 新增收益 |
| **需量电费** | 按最大功率收取的基本电费 | 工厂储能收益点 |
| **EPC 总包** | 设计+采购+施工的总承包 | 项目贷标的 |
| **设备租赁** | 客户租赁储能设备 | 设备制造商业绩 |
