# 新能源/储能 · 拓客渠道汇总(15 大渠道)

> **用途**: 客户经理系统化获取储能企业名单
> **原则**: 主动 + 持续 + 多渠道并行,不要单押一个渠道

---

## 渠道 1:行业协会(必入)

### 1.1 CNESA 中关村储能产业技术联盟

**适用场景**: 行业最权威 + 政策对接 + 项目库

**操作步骤**:
1. 访问 cnesa.org 申请个人会员(年费 1000-5000 元)
2. 加入微信群 + 参加月度沙龙
3. 获取 CNESA 项目数据库(全国储能项目清单)
4. 申请加入政策研究委员会

**实战技巧**:
- 入会第一年重点是"认识人",不是"拉客户"
- 主动在群里回答问题,建立专家人设
- 争取在 CNESA 年会上发言

**预期产出**: 50+ 家企业联系,3-5 家深度接触

### 1.2 深圳市新能源行业协会

**适用场景**: 本地企业 + 政府资源

**操作步骤**:
1. 访问 sz-nea.org 申请会员
2. 参加月度理事会(月会)
3. 申请加入"金融专委会"
4. 争取协会副会长/理事单位

**实战技巧**:
- 本地协会 = 政府背书,容易获取补贴名单
- 与协会联合举办"产融对接会"(银行出场地 + 协会邀客户)

**预期产出**: 30+ 家本地企业,5-10 家政策补贴名单

### 1.3 中国化学与物理电源行业协会

**适用场景**: 电池产业链

**操作步骤**: 类似 CNESA,参加锂电池分会

## 渠道 2:产业园区(深耕)

### 2.1 坪山比亚迪产业园

**操作步骤**:
1. 联系坪山区科技创新局生物医药产业办公室
2. 自我介绍 + 银行储能产品介绍
3. 获取园区入驻企业名单
4. 争取园区"产融对接会"

**实战技巧**:
- 比亚迪链上 5000+ 家小微,**金矿**
- 不要直接找比亚迪(议价权弱),只找链上
- 园区招商办是"金钥匙",搞定 1 个就搞定一片

**预期产出**: 100+ 家链上小微名单

### 2.2 光明储能产业基地

**操作步骤**:
1. 联系光明区工信局
2. 获取光明储能企业名单(政府有完整清单)
3. 走访光明区储能企业
4. 申请光明区"金融特派员"(政府背书)

**预期产出**: 50+ 家光明企业

### 2.3 宝安便携储能集群

**操作步骤**:
1. 联系宝安区科技创新局
2. 获取便携储能企业名单
3. 走访正浩/华宝上下游
4. 与深圳跨境电商协会合作

**预期产出**: 30+ 家便携储能企业

## 渠道 3:展会(每年必去)

### 3.1 SNEC 储能展(上海,每年 6 月)

**适用场景**: 头部企业 + 最新产品

**操作步骤**:
1. 提前 1 个月预约(免门票)
2. 准备 200 张名片 + 50 份银行产品手册
3. 重点走访 PCS/EMS 展位
4. 晚上参加行业晚宴(社交黄金时间)

**实战技巧**:
- 展会上 70% 时间社交,30% 看展品
- 主动说"我是 XX 银行,做储能方向" — 客户会主动加你
- 晚上约咖啡(单独聊,效果更好)

**预期产出**: 50+ 张名片,10-15 家深度接触

### 3.2 CIBF 中国电池展(深圳,每年 4 月)

**适用场景**: 深圳主场 + 电池产业链

**操作步骤**: 类似 SNEC,深圳主场优势

### 3.3 高工储能年会(每年 12 月)

**适用场景**: 行业总结 + 政策对接

**实战技巧**: 高工储能的客户主要是"集成商",银行机会大

## 渠道 4:VC 数据库(投贷联动)

### 4.1 IT 桔子

**操作步骤**:
1. 注册 IT 桔子账号(付费版 ~3000 元/年)
2. 筛选:深圳 + 储能 + A/B/C 轮
3. 获取 VC 投资企业名单 + 投资方
4. 主动联系 VC(投贷联动)

**实战技巧**:
- IT 桔子最准的"早期储能企业"数据源
- 投贷联动关键:**跟 VC 同步进入**,不要等企业找你
- 联系 VC 投资经理(不是企业),他帮你引荐

**预期产出**: 50+ 家早期储能企业 + VC 关系

### 4.2 烯牛数据 / 投中网

**操作步骤**: 类似 IT 桔子

### 4.3 各地政府产业基金

**操作步骤**:
1. 关注深圳天使母基金、深创投、达晨创投
2. 获取被投企业名单
3. 投贷联动

**适用场景**: 国家级认证,银行介入"金标准"

## 渠道 6:招投标数据(项目贷金矿)

### 6.1 中国招标投标公共服务平台

**适用场景**: 工商业储能项目 + 政府订单

**操作步骤**:
1. 注册账号(免费)
2. 筛选:储能 / 电池 / 充电桩 + 深圳/广东

- 招标方愿意提供"中标后融资需求"线索

**预期产出**: 每月 10+ 个项目线索

### 6.2 全国公共资源交易平台

**操作步骤**: 类似中国招标投标公共服务平台

**操作步骤**: 重点关注储能 + 充电桩 + 比亚迪链上

## 渠道 14:客户推荐(口碑传播)

### 14.1 老客户推荐

**操作步骤**:
1. 服务好 1 个客户 → 他会介绍 5 个
2. 给推荐人"答谢礼"(银行业务费 + 礼品)
3. 建立"老客户专属推荐群"

**实战技巧**:
- 推荐 = 银行最低成本获客
- 关键是"服务好第一个",不是"激励第二个"

**预期产出**: 1 个客户 → 3-5 个新客户

## 拓客原则(7 条)

1. **主动 > 被动**:不要等客户上门
2. **持续 > 一次性**:每周 1 次拓客动作
3. **多渠道 > 单押**:不要只用一个渠道
4. **质量 > 数量**:1000 家无效名单 < 50 家深度接触
5. **品牌 > 个人**:银行品牌 > 个人魅力
6. **专业 > 关系**:专业度是长期竞争力
7. **利他 > 推销**:先帮客户解决问题,再谈合作
