## 🤔 为什么这么多公司归"其他"?

我们的分类器用三重匹配:
1. **国标行业代码**(代码 276/277/358 = 医疗)
2. **经营范围关键词**(出现"机器人" = 机器人赛道)
3. **企业名关键词**(出现"生物" = 生物医药)

**匹配失败的常见原因**:
- 经营范围字段为空(60%+ 公司)
- 企业名是"深圳市 XX 科技有限公司",XX 无关键词(如"金木水火土")
- 国标代码是粗类(如"其他制造业")无法定位到赛道

**典型样本**:
- 深圳市中图仪器股份有限公司 — 行业"其他制造业",经营范围空
- 深圳精智达技术股份有限公司 — 行业"专用设备制造业",经营范围空
- 深圳市速腾聚创科技有限公司 — 行业"软件和信息技术服务业",关键词"聚创"无赛道匹配
  (但实际是激光雷达跨赛道企业!)

## 🎯 如何手动筛?(5 个策略)

### 策略 1:按注册资本排序(最快)

`00-全部客户清单.md` 默认是按"注册资本 × 1000 + 参保人数"降序。

**Top 100 by 注册资本** = 大概率是好客户(注册资本大 = 有实力)。

### 策略 2:看参保人数

参保人数反映实际经营规模:
- > 500 人 = 大型公司,值得联系
- 100-500 人 = 中型,值得调研
- < 50 人 = 小公司,先放着

### 策略 3:关键词搜索(用 Ctrl+K)

在 web 应用里按 `Ctrl+K`,输入关键词:
- "智能" "科技" "光电" "新能源" "精密" "医疗" "生物"

### 策略 4:补充经营范围

找 Top 50 大客户,去天眼查/企查查官网手动补经营范围。
补完后,跑 `python3 _classify_enhanced.py` 看能不能分类到具体赛道。

### 策略 5:批量改名分类

如果发现一批公司其实属于同一赛道(比如"XX 检测" 应该归"检验检测"),
可以直接在 `名单/_generate_industry_mds.py` 的 `SCOPE_KW` 字典里加新关键词:

```python
'检验检测': ['检测', '测试', '认证', '计量', '实验室', '质检', '化验', '分析测试'],  # 加"化验"
```

然后跑 `python3 _generate_industry_mds.py` 重新生成。

## 🔄 如何"升级"公司到对应赛道?

当你在 99-其他 找到一家其实属于具体赛道(如 EcoFlow 应该归"新能源/储能"),有两种方式:

### 方式 A:加关键词(影响所有类似公司)

改 `名单/_generate_industry_mds.py` 的 `SCOPE_KW`,然后重新生成。

### 方式 B:人工指定(只影响这一家)

在 CSV 里手动改 "行业代码" 字段为对应国标代码,然后重新生成。

**推荐方式 A** — 一处改,所有类似公司受益。
